# Kelompok_4
Reposito Kelompok 4 Berisi Tentang Project & Proges Sistem Peminjaman Kitab (
Aplikasi web manajemen dan sistem informasi peminjaman kitab digital/fisik yang dirancang untuk memudahkan proses pendataan, peminjaman, pengembalian, serta pencatatan riwayat transaksi kitab secara terstruktur.

1.Fitur Utama
Manajemen Data Kitab: Tambah, edit, hapus, dan cari katalog kitab berdasarkan kategori, pengarang, atau stok yang tersedia.
Manajemen Anggota/Siswa: Pendaftaran dan pengelolaan data peminjam.
Transaksi Peminjaman & Pengembalian: Catat tanggal pinjam, tenggat waktu (deadline), dan status pengembalian kitab secara real-time.
Riwayat & Laporan: Rekapitulasi data peminjaman untuk memudahkan monitoring admin.

2.Teknologi yang Digunakan
Frontend: HTML5, CSS, JavaScript, ( Bootstrap )
Backend: PHP
Database: MySQL
Version Control: GitHub
